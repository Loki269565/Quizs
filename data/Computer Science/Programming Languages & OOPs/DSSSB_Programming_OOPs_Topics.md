# DSSSB — Programming Languages & OOPs: Complete Topic List

## 1. Fundamentals of Programming
- Algorithm, flowchart, pseudocode
- Compiler vs Interpreter vs Assembler
- Structured programming concepts
- Variables, data types, type conversion (implicit/explicit)
- Operators (arithmetic, relational, logical, bitwise, assignment, ternary, comma)
- Operator precedence and associativity
- Control structures: if-else, switch-case, loops (for, while, do-while)
- Break, continue, goto
- Functions: declaration, definition, call, recursion
- Storage classes: auto, static, register, extern
- Scope and lifetime of variables

## 2. C Language
- Arrays (1D, 2D, multidimensional)
- Strings and string handling functions
- Pointers: declaration, arithmetic, pointer to pointer, function pointers
- Pointers and arrays, pointers and strings
- Structures and Unions
- Enumerations
- Dynamic memory allocation (malloc, calloc, realloc, free)
- File handling (fopen, fclose, fread, fwrite, fprintf, fscanf)
- Preprocessor directives (#define, #include, macros, conditional compilation)
- Command line arguments
- Storage of arrays/structures in memory, padding

## 3. C++ Specific Concepts
- Difference between C and C++
- Namespaces
- Reference variables vs pointers
- Function overloading
- Default arguments
- Inline functions
- `new` and `delete` operators
- `this` pointer
- Friend function and friend class
- Static members (data & function)
- Const keyword (const objects, const member functions)
- Exception handling (try, catch, throw)
- Templates (function templates, class templates)
- STL basics (vector, list, map, set, stack, queue, iterators) — often asked conceptually

## 4. Object-Oriented Programming (OOPs) — Core Concepts
- **Class and Object**
- **Encapsulation** (data hiding)
- **Abstraction**
- **Inheritance**
  - Single, Multiple, Multilevel, Hierarchical, Hybrid
  - Base class, derived class
  - Access specifiers in inheritance (public, private, protected)
  - Virtual base class (diamond problem)
- **Polymorphism**
  - Compile-time (function overloading, operator overloading)
  - Run-time (virtual functions, function overriding)
  - Pure virtual functions and abstract classes
- **Constructors and Destructors**
  - Default, parameterized, copy constructor
  - Constructor overloading
  - Destructor rules
  - Order of constructor/destructor calls in inheritance
- **Operator Overloading**
  - Unary and binary operator overloading
  - Overloading using member function vs friend function
- **Virtual Functions and Dynamic Binding**
  - Virtual table (vtable) concept
  - Early binding vs late binding
- **Abstract Class vs Interface concept**
- **Object composition/aggregation vs inheritance**
- Access modifiers: private, public, protected

## 5. Java (frequently tested alongside C++)
- JVM, JRE, JDK
- Data types, type casting
- Class, object, constructor
- Inheritance (extends), interfaces (implements)
- `super` and `this` keyword
- Method overloading vs overriding
- Abstract class vs Interface in Java
- Access modifiers (private, public, protected, default)
- Exception handling (try-catch-finally, throw, throws, custom exceptions)
- Static and final keywords
- Packages
- Multithreading basics
- String class, StringBuffer, StringBuilder
- Wrapper classes
- Garbage collection concept
- Array handling in Java

## 6. Memory Management & Related Concepts
- Stack vs Heap memory
- Static vs dynamic memory allocation
- Memory leak, dangling pointer
- Shallow copy vs deep copy
- Object slicing

## 7. Programming Paradigms (Conceptual/Theory)
- Procedural vs Object-Oriented vs Functional programming
- Advantages of OOP over procedural programming
- Real-world examples mapped to OOP concepts (very common MCQ style)

## 8. Common MCQ-Style Areas (Output/Error-based Questions)
- Predict output of C/C++/Java code snippets
- Find compilation errors
- Trace pointer arithmetic
- Trace recursive function output
- Identify constructor/destructor call sequence
- Identify overloading vs overriding in given code

## 9. Software Engineering Basics (sometimes clubbed in same section)
- SDLC models (Waterfall, Spiral, Agile) — basic definitions
- Testing types (unit, integration, black box, white box) — basic level

---

### Suggested Study Order
1. C fundamentals → 2. Pointers/Structures → 3. OOP theory (encapsulation, inheritance, polymorphism, abstraction) → 4. C++ implementation of OOP → 5. Java equivalents → 6. Practice output-based MCQs (most repeated question type in DSSSB).

> Tip: DSSSB CS papers heavily favor **"predict the output"** and **"identify the OOP concept"** style questions over pure theory definitions — prioritize code-tracing practice.

# DSSSB TGT Computer Science — Computer Networks Full Syllabus

Complete topic-wise breakdown for exam preparation. DSSSB officially lists "Computer Networks" as one broad unit — yeh document usse detailed, exam-oriented sub-topics mein todta hai jo generally poochhe jaate hain.

---

## Unit 1: Introduction to Networking

- Data communication basics — components (sender, receiver, medium, protocol, message)
- Types of networks: LAN, MAN, WAN, PAN, CAN, SAN
- Network topologies: Bus, Star, Ring, Mesh, Tree, Hybrid — advantages/disadvantages
- Network classifications: peer-to-peer vs client-server
- Transmission modes: Simplex, Half-duplex, Full-duplex
- Switching techniques: Circuit switching, Packet switching, Message switching
- Internet vs Intranet vs Extranet
- Analog vs Digital signals, Bandwidth, Data rate, Baud rate

## Unit 2: Reference Models

- **OSI Reference Model** — all 7 layers, functions of each layer, layer-wise protocols/devices
- **TCP/IP Reference Model** — 4/5 layers, comparison with OSI
- Protocol Data Units (PDU) at each layer
- Encapsulation and De-encapsulation concept

## Unit 3: Physical Layer

- Guided transmission media: Twisted Pair (UTP/STP), Coaxial Cable, Fiber Optic Cable
- Unguided/wireless media: Radio waves, Microwaves, Infrared, Satellite communication
- Multiplexing: FDM, TDM, WDM, CDM (concept level)
- Switching at physical level, Modems
- Transmission impairments: Attenuation, Distortion, Noise

## Unit 4: Data Link Layer

- Functions: Framing, Flow control, Error control, Access control
- Error detection & correction: Parity check, Checksum, CRC (Cyclic Redundancy Check), Hamming Code
- Flow control protocols: Stop-and-Wait, Sliding Window (Go-Back-N, Selective Repeat)
- Medium Access Control (MAC) protocols:
  - ALOHA (Pure & Slotted)
  - CSMA, CSMA/CD, CSMA/CA
  - Token Passing, Token Ring, Token Bus
- LAN standards: Ethernet (IEEE 802.3), Wi-Fi (IEEE 802.11), Bluetooth (IEEE 802.15)
- Devices: Hub, Switch, Bridge, NIC, Repeater
- MAC address, ARP, RARP

## Unit 5: Network Layer

- IP Addressing: IPv4 (classful & classless — CIDR), IPv6 basics
- Subnetting and Supernetting
- Routing: Static vs Dynamic routing
- Routing algorithms/protocols: Distance Vector (RIP), Link State (OSPF), Path Vector (BGP)
- Congestion control techniques
- Network layer protocols: IP, ICMP, IGMP
- NAT (Network Address Translation)
- Router — working and functions
- Fragmentation and Reassembly of packets

## Unit 6: Transport Layer

- Functions: Process-to-process delivery, Segmentation, Multiplexing
- Protocols: TCP (Transmission Control Protocol) — connection-oriented, 3-way handshake
- UDP (User Datagram Protocol) — connectionless
- TCP vs UDP comparison
- Port numbers, Sockets
- Flow control & Congestion control in TCP (Sliding window, Slow start, Congestion avoidance)
- Quality of Service (QoS)

## Unit 7: Application Layer

- DNS (Domain Name System) — working, hierarchy
- HTTP and HTTPS
- FTP (File Transfer Protocol), TFTP
- SMTP, POP3, IMAP (Email protocols)
- Telnet, SSH
- DHCP (Dynamic Host Configuration Protocol)
- SNMP (Simple Network Management Protocol)
- WWW basics, Web browsers, URLs

## Unit 8: Network Security

- Cryptography basics: Symmetric vs Asymmetric key encryption
- Common algorithms (concept level): DES, RSA
- Digital Signature, Digital Certificate
- Firewalls — types and function
- Types of attacks: Virus, Worm, Trojan Horse, Phishing, DoS/DDoS, Spoofing
- Network security devices: Firewall, IDS/IPS, Proxy server
- SSL/TLS basics
- VPN (Virtual Private Network)

## Unit 9: Wireless & Mobile Networking

- Wireless LAN (WLAN) basics, IEEE 802.11 standards (a/b/g/n/ac)
- Bluetooth, Infrared
- Mobile communication generations: 1G, 2G, 3G, 4G, 5G (basic differences)
- Cellular network concepts: Cell, Handoff, Roaming
- WiMAX basics

## Unit 10: Network Devices (Consolidated)

- Repeater, Hub, Bridge, Switch, Router, Gateway, Access Point, Modem
- Layer-wise mapping of each device (which OSI layer it operates at)

## Unit 11: Miscellaneous / Frequently Asked

- Client-Server architecture vs Peer-to-Peer
- Cloud computing basics (as networking application)
- Network topology diagrams — identification-based questions
- Numerical questions: subnetting, CRC calculation, Hamming code, bandwidth-delay product
- Important RFC-based protocol port numbers (HTTP-80, HTTPS-443, FTP-20/21, SMTP-25, DNS-53, Telnet-23, SSH-22, POP3-110, IMAP-143, DHCP-67/68)

---

### Preparation Tips
- Numericals (subnetting, CRC, Hamming code) aksar aate hain — practice zaroor karein.
- OSI layer ke functions aur unke corresponding protocols/devices ratna high-weightage topic hai.
- Port numbers aur protocol acronyms MCQs mein bahut common hain.
- Previous year DSSSB TGT/PGT papers se pattern samjhein — networking se 8-12 questions tak aa sakte hain.
